# EnglishWords — 2안부터 6안 비교

기초부터 고등학교 과정까지 이어지는 영단어 학습기, A1~C1 영문법 학습기, 노션 기반 120단계 문법 교재를 비교하는 정적 웹사이트입니다.

- `02 2안`: 세션 중심의 단계형 학습 방식
- `03 3안`: 묶음 스캔, 표본 검증, 수행 기반 자동 복습 방식
- `04 4안`: 개념 강의와 네 가지 실전 훈련을 결합한 기존 영문법 학습 방식
- `05 5안`: 문장을 관찰·분해·재조립하고 수행 근거로 간격 복습하는 문장 설계 스튜디오
- `06 6안`: 노션 120단계 순서를 유지한 개념 중심 문법 교재. 해설 예문·표현 비교·노트·자기 설명 기반 간격 복습
