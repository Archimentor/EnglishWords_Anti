- 시각 방향: 따뜻한 종이색, 짙은 잉크색, 녹색 한 가지 강조색을 사용한 조용한 디지털 교재.
- 콘텐츠 구조: 120단계 목차 → 원리·형식·해설 예문·혼동 비교·관련 단계 → 선택형 회상/작문 → 읽기 완료 및 다음 단계.
- 상호작용: 목차/읽던 위치 이어가기, 펼쳐 보는 해설, 짧은 상태 전환. 동작 줄이기 설정을 존중한다.
- 모바일: 접을 수 있는 목차, 한 열 본문, 줄바꿈되는 문법식. 인쇄용 레이아웃.

## 범위와 정직한 표시

### 2026-09-29 내용 깊이 수정

사용자가 제시한 83단계 예시는 짧은 개요가 아니라 상황, 구조, 유사 표현 3종 비교, 부정형, 여러 실용 예문, 핵심 정리와 선택 연습으로 구성된 상세 교재다. 기존 두 문단/두 예문의 초안은 최종 기준에 미달한다. 배포를 보류하고 120단계 모두 주제별 추가 강의를 작성한다. 섹션 수만 늘리거나 공통 문구를 반복하지 않고, 각 문법의 세부 용법과 의미 차이를 직접 설명한다. 83단계의 전체 예시를 먼저 반영하고, 다른 단계도 동일한 깊이의 본문으로 확장한 뒤 전수 검증한다.

- 원본에 CEFR 단계별 배정이 없으므로 임의의 공인 등급 대응표를 만들지 않는다.
- 교재 중심 비율은 화면 구성 방침이며 실제 사용 시간이나 숙련도 측정치가 아니다.
- 읽기 완료와 기억 여부를 구분한다. 복습은 자기 설명 후 자기평가이며 자동 문법 채점이 아니다.
- 복습 간격은 운영용 기본값이며 개인의 망각곡선을 측정했다는 주장을 하지 않는다.
- 브라우저 저장은 기기 간 자동 동기화되지 않는다. 백업/복원과 저장 실패 안내를 제공한다.
