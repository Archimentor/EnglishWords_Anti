# 6안 · 원문 교재 전환

## 사용자 승인 범위

2026-09-29: 공유 대화의 1–83단계를 원문의 표현과 형태를 최대한 유지해 옮긴다. 명백한 오류는 수정하되 수정내역을 본문에 표시하지 않는다. 84–120단계는 기존 과정 목차를 따라 같은 설명 방식과 깊이로 작성한다. 기존 6안에 적용하여 재배포한다.

## 구현 방향

1. 전체 공유 대화에서 실제 번호가 붙은 83개 강의를 중복·누락 없이 추출한다.
2. 원문을 단계별 Markdown으로 보관한다. 제목·문단·인용·강조·표·연습의 순서를 보존한다.
3. 84–120단계를 각각의 주제에 맞게 집필한다. 원문처럼 상황과 예문으로 설명하며 획일적인 짧은 요약 틀을 적용하지 않는다.
4. 본문을 안전한 정적 HTML로 빌드한다. 빌드 시 원시 HTML·이미지·위험한 링크를 차단하며 브라우저에서는 외부 변환 API를 사용하지 않는다.
5. 본문 중심의 읽기 화면에 실제 소제목 목차를 제공한다. 선택 활동·노트·완료·이동 기능은 본문 뒤에 둔다.
6. 기존 저장 키·백업 형식·복습 일정을 유지하고 옛 링크와 새 읽기 위치를 함께 지원한다.
7. 원문 전수 대조, 120단계 정적·실제 렌더링, 저장·복원, 모바일·인쇄 검사를 수행한다.
8. 6안 변경만 커밋·푸시하여 GitHub Pages를 확인한다. 작업용 탭과 임시 서버는 종료한다.

## 유지할 원칙

- 학습의 중심은 상세한 개념 설명이다. 문제 풀이·점수·연속 출석을 다음 단계의 조건으로 삼지 않는다.
- 읽기 완료와 회상 성공은 다르다. 복습 일정은 운영 기본값이지 개인별 망각곡선 측정 결과가 아니다.
- 원문 전체 HTML이나 대화 메타데이터는 배포하지 않는다.
- 2–5안의 콘텐츠·학습 기록·배포 구조를 변경하지 않는다.
- Notion 원문을 수정하지 않는다.
