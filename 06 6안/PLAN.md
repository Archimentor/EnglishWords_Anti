# 6안 · 최신 노션 원문 동기화

## 사용자 요청

2026-09-30: 노션에서 업데이트한 1–120단계를 확인하여 원문 그대로 옮긴다. 기존 6안의 읽기 화면과 학습 기록을 유지하여 배포 사이트에 반영한다.

## 구현 순서

1. 노션 목차와 120개 단계별 페이지의 전체 본문을 읽기 전용으로 확보한다.
2. 단계 번호·제목·URL·완전성을 검증한다. 누락·중복·잘린 응답·미지원 블록은 반영 전에 중단한다.
3. 실제 페이지 제목과 본문을 그대로 저장한다. 별도 요약·교정이나 이전 집필 원고의 혼합을 하지 않는다.
4. 블록 경계·줄바꿈·표·강조의 실패 테스트를 작성하고 렌더러 수정 후 통과를 확인한다.
5. 원문 SHA-256·전체 문자열, 생성 HTML의 표시 단어·숫자 순서, 모든 표·목차를 전수 검증한다.
6. 저장 키·백업 형식·복습 일정은 유지하고 안내 문구·캐시 버전을 최신 출처에 맞춘다.
7. 실제 브라우저에서 120단계와 모바일 화면, 이전 링크·학습 기록 유지를 확인한다.
8. 관련 파일을 커밋·푸시하고 GitHub Pages 빌드·공개 파일 일치를 확인한다. 작업용 탭·서버·자식 프로세스를 정리한다.

## 유지할 원칙

- 학습의 중심은 상세한 개념 설명이다. 문제 풀이·점수를 다음 단계의 조건으로 삼지 않는다.
- 읽기 완료와 회상 성공은 다르며 복습 간격은 개인별 망각곡선 측정값이 아니다.
- 노션 원본은 수정하지 않는다. 응답의 개인적인 상위 경로 등 불필요한 메타데이터는 배포하지 않는다.
- 2–5안의 콘텐츠·학습 기록·배포 구조를 변경하지 않는다.
