# 77단계 — `if only`

`if only`는 `wish`와 비슷하지만 **아쉬움이나 바람을 더 강하게** 표현한다.

핵심:

> **if only + 과거형** = 지금 ~라면 얼마나 좋을까  
> **if only + had + p.p.** = 그때 ~했더라면 얼마나 좋았을까  
> **if only + would + 동사원형** = 제발 ~해주면 좋을 텐데

---

## 1. 현재 사실과 반대

> **If only I had more time.**

> 시간이 더 많으면 정말 좋을 텐데.

실제:

> 지금 시간이 부족하다.

`wish`로 바꾸면:

> I wish I had more time.

둘 다 비슷하지만 `if only`가 보통 감정이 더 강하다.

---

# 2. `If only I were...`

> If only I **were younger**.

> 내가 좀 더 젊다면 얼마나 좋을까.

실제:

> 나는 지금 더 젊지 않다.

가정법과 마찬가지로:

> **were**

를 기본형으로 쓴다.

---

# 3. 과거에 대한 후회

구조:

> **if only + had + p.p.**

예:

> If only I **had studied** harder.

> 내가 더 열심히 공부했더라면 얼마나 좋았을까.

실제:

> 충분히 공부하지 않았다.

---

# 4. `wish`와 비교

### wish

> I wish I had called her.

> 그녀에게 전화했더라면 좋았을 텐데.

### if only

> If only I had called her!

> 그때 그녀한테 전화만 했더라면!

`if only` 쪽이 **후회나 감정이 더 강하게** 느껴진다.

---

# 5. 문장 하나만으로도 완전한 표현

보통 `if`를 보면 뒤에 결과절이 필요하다고 생각할 수 있다.

예:

> If I have time, I'll go.

하지만 `if only`는 독립적으로 끝날 수 있다.

> If only I knew!

> 내가 알기만 한다면!

> If only she were here!

> 그녀가 여기 있기만 한다면!

뒤에 `I would...` 같은 결과절이 없어도 된다.

---

# 6. `if only + would`

상대방이나 상황이 **좀 바뀌었으면 하는 강한 바람**이다.

> If only you **would listen** to me.

> 제발 내 말 좀 들어주면 좋을 텐데.

> If only it **would stop raining**.

> 비가 제발 좀 그치면 좋을 텐데.

`wish + would`와 매우 비슷하다.

---

# 7. 세 가지 시점

## 현재가 아쉬움

> If only I **had** more money.

> 지금 돈이 더 있다면 좋을 텐데.

---

## 과거가 아쉬움

> If only I **had had** more money.

> 그때 돈이 더 있었더라면 좋았을 텐데.

---

## 앞으로 상황이 바뀌길 바람

> If only he **would call** me.

> 그가 제발 전화해주면 좋을 텐데.

---

# 8. `only if`와 혼동하면 안 된다

이 둘은 완전히 다르다.

### if only

> **~라면 얼마나 좋을까**

> If only I had more time.

---

### only if

> **오직 ~하는 경우에만**

> You can go **only if you finish your work**.

> 일을 끝내야만 갈 수 있다.

단어 순서만 바뀌었는데 의미가 완전히 달라진다.

---

# 핵심

### 현재 아쉬움

> **If only + 과거형**

> If only I were rich.

### 과거 후회

> **If only + had + p.p.**

> If only I had known.

### 변화 바람

> **If only + would + 동사원형**

> If only you would stop.

그리고:

> `wish`보다 보통 **감정이 더 강하다.**

---

## 연습

맞는 것을 골라봐.

1. If only I **have / had** more time.
2. If only she **were / is** here.
3. If only I **had known / knew** about it yesterday.
4. If only you **would listen / will listen** to me.
5. **If only / Only if** I were younger!  
   → 내가 좀 더 젊다면 얼마나 좋을까.
6. You can leave **if only / only if** you finish the work.  
   → 일을 끝낸 경우에만 떠날 수 있다.
