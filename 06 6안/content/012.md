# 12단계 — some / any

이번에는 수량이 정확하지 않을 때 쓰는 가장 기본적인 표현을 배운다.
핵심은 이것이다.
**some = 어느 정도 있다**
**any = 있는지 없는지 열어둔다**
## 1. some
보통 긍정문에서 쓴다.
I have some books.  
나는 책이 좀 있다.
I need some water.  
나는 물이 좀 필요하다.
중요한 점:
some은 **가산명사 복수와 불가산명사 둘 다** 쓸 수 있다.
가산명사 복수:
some books  
some apples  
some chairs
불가산명사:
some water  
some information  
some advice
## 2. 왜 some book은 안 되나?
book은 가산명사다.
한 권이면:
a book
여러 권인데 정확한 수를 말하지 않으면:
some books
따라서:
some book ❌  
some books ✅
반면 water는 불가산명사라 복수형이 필요 없다.
some water
## 3. any
any는 주로 의문문과 부정문에서 쓴다.
의문문:
Do you have any books?  
책 있어?
Do you have any water?  
물 있어?
여기서 any는:
하나라도 있는지 / 어느 정도라도 있는지
확인하는 느낌이다.
## 4. 부정문
I don't have any books.  
나는 책이 하나도 없다.
I don't have any water.  
나는 물이 전혀 없다.
즉:
**not + any**
가 만나면 보통 “하나도 없다 / 전혀 없다”라는 의미가 된다.
## 5. 기본 패턴
긍정:
I have some money.
의문:
Do you have any money?
부정:
I don't have any money.
## 6. some과 any를 단순히 긍정/부정으로만 외우면 안 된다
기본 규칙은:
- 긍정문 → some
- 의문문 → any
- 부정문 → any
하지만 실제 의미가 더 중요하다.
## 7. 질문인데 some을 쓰는 경우
상대방이 그렇다고 예상하거나, 무언가를 권하거나 요청할 때 some을 쓸 수 있다.
Would you like some coffee?  
커피 좀 드실래요?
any coffee라고 하지 않는 이유는 단순히 “커피가 있습니까?”라고 존재 여부를 묻는 게 아니라 “커피를 드릴까요?”라는 제안이기 때문이다.
또:
Can I have some water?  
물 좀 주실 수 있어요?
물을 받을 것을 어느 정도 기대하면서 요청한다.
## 8. any가 긍정문에 나오는 경우
any는 긍정문에서:
**어떤 것이든 / 아무거나**
라는 뜻도 가진다.
You can choose any book.
어떤 책이든 골라도 돼.
여기서는 any book처럼 단수명사도 올 수 있다.
이것은 지금 배우는 “수량 표현 any”와 의미가 조금 다르므로 지금은 구별만 해두면 된다.
## 9. 지금까지 연결
가산 단수:
a book
가산 복수:
books  
some books
불가산:
water  
some water
그리고 질문이나 부정에서는:
any books  
any water
## 핵심
some = 어느 정도 존재한다고 보는 표현
I have some friends.
any = 존재 여부를 열어두거나 부정하는 표현
Do you have any friends?  
I don't have any friends.
