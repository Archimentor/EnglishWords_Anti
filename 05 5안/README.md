# 05 5안 — Grammar Blueprint

A1부터 C1까지 문법을 **문장 설계 능력**으로 익히는 실습형 학습기입니다. 문제를 먼저 던지는 방식 대신, 각 단원을 아래 6개 작업대로 순서대로 학습한 뒤 수행을 확인합니다.

1. 설계 브리프 — 학습 목표와 핵심 질문
2. 의미 관찰 — 한국어 화자가 놓치기 쉬운 의미 차이
3. 형태 원리 — 공식, 성분, 예문, 함정 비교
4. 문장 설계도 — 문장 성분을 눌러 역할 분석
5. 오류 수리 — 실제 오문을 고치며 규칙 설명
6. 직접 전이 — 배운 구조로 새 문장을 작성하고 자동 저장

## 학습 범위

- CEFR A1, A2, B1, B2, C1
- 레벨별 8개, 총 40개 단원
- 판별·오류 수리·구조 조립·형태 변환 4종 수행 문장
- 정확도, 힌트 사용, 응답 속도를 반영한 간격 복습
- 진행 상황, 취약 유형, 다음 복습 시점을 브라우저에 저장

## 실행과 검증

별도 빌드 없이 `index.html`을 열거나 정적 서버로 실행할 수 있습니다.

```powershell
node ".\05 5안\scripts\verify_grammar_studio.mjs"
python -m http.server 4173
```

학습 기록은 `grammar_blueprint_option5_v1` 키로 `localStorage`에 저장됩니다. 이전 5안 기록이 있으면 레벨·학습 시간·소리·연속 학습 설정을 한 번만 이어받습니다.
