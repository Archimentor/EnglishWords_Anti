# Grammar Lab — A1~C1 문법 학습기

각 문법을 교재처럼 상세히 이해한 뒤 필요한 만큼만 문장으로 확인하는 개념 중심 정적 웹 학습기입니다. 한 단원의 기본 비중은 **개념 교재 85% / 확인 연습 15%**입니다.

## 학습 범위

| 수준 | 주제 | 문장 문제 | 핵심 범위 |
|---|---:|---:|---|
| A1 | 8 | 24 | be·have got, 현재·과거, 기본 질문, 진행형, 존재·수량, can·명령문, 전치사 |
| A2 | 8 | 24 | 기본 시제, 미래 표현, 관사·수량, 비교, 조동사, 동사형, 1형 조건문 |
| B1 | 8 | 24 | 현재·과거완료, 조건문, 수동태, 관계절, 간접화법, 과거 습관, 동사 문형 |
| B2 | 8 | 24 | 완료진행, 미래완료, 3형·혼합 조건문, 과거 추론, 사역·보고 수동, 대조, 가정법 |
| C1 | 8 | 24 | 부정어·조건 도치, 분열문, 분사절, 고급 수동, 생략·대용, 비현실 시제, 완곡화 |

총 40개 주제와 120개 보조 문장 문제를 제공합니다. A1 8개 단원에는 각각 7절로 구성된 상세 개념 강의가 들어 있습니다.

## 학습 흐름

1. **강의 안내**: 개념이 필요한 이유와 학습 목표를 먼저 확인합니다.
2. **핵심 개념**: 규칙을 암기하기 전에 의미와 작동 원리를 한국어로 상세히 읽습니다.
3. **형태 변화표**: 긍정·부정·질문 형태를 눌러 실제 예문과 함께 비교합니다.
4. **쓰는 상황**: 같은 형태라도 언제 자연스럽고 언제 어색한지 구분합니다.
5. **한국어와 비교**: 한국어 화자가 직역하며 생기는 오류를 대조합니다.
6. **문장 해설**: 완성 문장을 주어·동사·보어 등 성분별로 해체해 읽습니다.
7. **오류와 정리**: 대표 오류의 원인을 확인하고 한 페이지 요약으로 마무리합니다.
8. **선택 연습**: 개념 강의를 완료한 뒤에만 조립·직접 입력·맥락 선택 3문제로 확인합니다.

10문장 수준 진단은 첫 화면의 선택 기능이며, A1 개념 학습을 시작하는 데 필요하지 않습니다.

학습 기록은 브라우저 `localStorage`에만 저장됩니다. 별도 로그인, 서버, 빌드 과정이 없습니다.

## 실행

`index.html`을 직접 열거나 이 폴더에서 정적 서버를 실행합니다.

```powershell
python -m http.server 8765
```

그런 다음 `http://127.0.0.1:8765`를 엽니다.

## 검증

```powershell
node scripts/verify_grammar_lab.mjs
```

검증기는 수준별 주제 수, 문항 구조, 중복 ID, 정답 판정, 진단 표본, 복습 간격뿐 아니라 A1 8개 상세 강의의 목표·개념·형태표·쓰임·한국어 대조·문장 해설·오류 사례와 최소 콘텐츠 깊이를 검사합니다.
