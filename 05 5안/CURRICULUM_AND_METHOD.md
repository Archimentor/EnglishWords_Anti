# 커리큘럼과 학습 방식 근거

조사일: 2026-09-01

## 커리큘럼 기준

- [English Grammar Profile](https://englishprofile.org/?menu=english-grammar-profile)은 같은 문법 형태도 의미와 화용적 쓰임에 따라 등장 수준이 달라진다는 관점으로 CEFR 문법 발달을 정리합니다.
- [British Council A1–A2 grammar](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2), [B1–B2 grammar](https://learnenglish.britishcouncil.org/free-resources/grammar/b1-b2), [C1 grammar](https://learnenglish.britishcouncil.org/free-resources/grammar/c1)의 주제 목록과 수준 설명을 대조해 A1~C1 핵심 범위를 배치했습니다.
- CEFR 수준은 단순한 규칙의 난도가 아니라 실제 의사소통 기능의 확장으로 해석했습니다. A1은 기본적인 사람·사물·일상 묘사, A2는 일상적 교환, B1은 친숙한 주제의 연결된 표현, B2는 복잡한 내용과 의견 표현, C1은 사회·학업·업무 맥락에서 유연하고 정교한 사용을 목표로 합니다.

## 학습 방식 기준

1. **개념 교재 85% → 선택 연습 15%**

   5안의 주 흐름은 개념을 먼저 충분히 배우는 교재형 강의입니다. 수준 진단은 선택 사항으로 분리하고, 각 단원의 설명을 모두 학습한 뒤에만 짧은 확인 연습을 제공합니다. British Council의 Test → Teach → Test 방식은 선택 진단과 사후 확인에만 제한적으로 적용합니다.

   [How to use the LearnEnglish grammar section](https://learnenglish.britishcouncil.org/english-levels/improve-your-english-level/how-use-learnenglish-grammar-section)

2. **형태·의미·쓰임을 먼저 연결**

   문법을 공식 하나로 축소하지 않고 ‘왜 필요한가, 형태가 어떻게 변하는가, 어떤 상황에서 쓰는가’를 하나의 강의 안에서 연결합니다. 한국어와의 차이와 문장 성분별 해설도 독립된 절로 제공합니다.

3. **이해와 생성을 서로 다른 비중으로 사용**

   문법 이해와 문장 생성은 서로 다른 역할을 하므로 둘을 모두 사용하되, 초점은 상세 개념 이해에 둡니다. 생성은 개념을 대체하지 않고 마지막 15%의 확인 도구로만 사용합니다.

   [Comprehension and Production Practice in Grammar Instruction](https://doi.org/10.37546/JALTJJ23.1-1)

4. **규칙 인식, 생성, 즉시 교정의 연결**

   의미를 가진 입력과 출력의 연결, 생성 연습, 교정 피드백을 묶은 활동은 목표 구조의 장기적 사용에 긍정적 결과를 보였습니다.

   [Effects of an input–output mapping practice task](https://doi.org/10.1016/j.system.2013.03.008)

5. **한 주제 반복 후 교차 복습**

   처음에는 한 구조를 집중적으로 배우되, 이후 복습에서는 여러 문법을 섞어 어떤 구조가 필요한지 구별하게 합니다.

   [Mixing Grammar Exercises Facilitates Long-Term Retention](https://eric.ed.gov/?id=EJ1225042)

## 구현 원칙

- 자기평가 버튼으로 숙련도를 정하지 않습니다.
- 문제를 풀어야만 문법 설명을 볼 수 있게 하지 않습니다.
- 교재 강의의 읽은 절과 완료 여부를 문제 점수와 별도로 기록합니다.
- 정답, 응답 시간, 힌트, 누적 성공을 근거로 복습을 예약합니다.
- 한 번의 정답을 영구 숙달로 처리하지 않습니다.
- 모든 예문과 문항은 이 프로젝트를 위해 새로 작성했습니다.
