# wordline

CEFR A1에서 C1까지 단계별로 학습하는 적응형 영단어 학습기입니다. 이미 아는 단어를 카드로 하나씩 확인하지 않고, 여러 단어를 한 번에 훑어 모르는 것만 골라냅니다.

## 커리큘럼 규모

| 단계 | 새 단어 | 누적 단어 | 학습 범위 |
|---|---:|---:|---|
| A1 | 1,019 | 1,019 | 기초·초등 입문 |
| A2 | 1,155 | 2,174 | 초등 완성 |
| B1 | 1,969 | 4,143 | 중등 기본 |
| B2 | 2,066 | 6,209 | 중등 심화·고등 기본 |
| C1 | 673 | 6,882 | 고등 심화·수능 이후 |

동일한 표제어가 여러 품사나 단계에 등장하면 가장 이른 CEFR 단계에 한 번만 배치합니다. 각 단계는 20단어 단위 학습 유닛으로 자동 구성됩니다.

## 학습 방식

1. **45초 범위 스캔**: CEFR 전 구간의 25개 표본을 한 화면에서 훑고, 뜻이 떠오르지 않는 단어만 골라 출발점을 찾습니다.
2. **묶음 단어 레이더**: 5분은 16개, 10분은 24개, 15분은 32개를 한꺼번에 보여줍니다. 아는 단어에는 아무 조작도 하지 않습니다.
3. **표본 검증과 묶음 통과**: 선택하지 않은 단어 가운데 2~4개만 실제 뜻 회상으로 검사합니다. 전부 맞히면 같은 묶음의 나머지는 잠정 통과하고, 틀리면 성급하게 숙달 처리하지 않습니다.
4. **빈틈만 문맥 학습**: 직접 고른 단어와 표본 검사에서 틀린 단어만 뜻·발음·예문을 학습합니다.
5. **자기평가 없는 자동 간격**: `다시 · 어려움 · 기억함 · 쉬움` 버튼을 사용하지 않습니다. 실제 정답, 응답 시간, 힌트 사용, 누적 성공 기록으로 다음 복습 시점을 계산합니다.
6. **혼합 회상**: 뜻 선택, 역방향 연결, 문맥 빈칸, 듣기, 철자 인출을 섞어 수동 인지가 아닌 실제 기억을 확인합니다.

추가로 6,882개 전체 검색, CEFR·기억 상태 필터, 북마크, 브라우저 발음, 주간 기록과 단계별 장기 기억 현황을 제공합니다. 모든 기록은 브라우저 `localStorage`에 저장되며 이전 3안 기록은 새 기억 모델로 자동 변환됩니다. 서비스·연구 조사와 기능별 적용 근거는 [RESEARCH_AND_DESIGN.md](RESEARCH_AND_DESIGN.md)에 정리했습니다.

## 실행

`index.html`을 직접 열어도 동작합니다. 로컬 서버로 실행하려면 이 폴더에서 다음 명령을 사용합니다.

```powershell
python -m http.server 8765
```

그런 다음 브라우저에서 `http://127.0.0.1:8765`를 엽니다. 별도 설치나 빌드 과정은 없습니다.

데이터의 출처와 이용 조건은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 정리되어 있습니다.

## 데이터 검증

```powershell
node scripts/verify_curriculum.mjs
node scripts/verify_learning_engine.mjs
```

첫 번째 검증기는 단계 순서, 레벨별 개수, 누적 개수, 중복 표제어, 유닛 누락, 뜻·문맥·IPA 커버리지를 검사합니다. 두 번째 검증기는 복습 간격, 자동 성과 판정, 표본 선택, 잠정 통과, 스캔 보류와 시간별 분량을 검사합니다.
